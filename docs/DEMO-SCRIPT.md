# 本地实测脚本（1→5）

http://localhost:3000/

旧数据干扰：F12 → Application → Local Storage → 删除 `skill-zoo:v1` → 刷新。

---

## 1. 商城

左侧 **Skill Zoo**。

应看到：

- 「50 个方法，13 位作者，正在让经验发芽」
- 排序 **热度榜**
- 热度条 NO.1：**热度 330 法律论文精读 陈沐**
- 卡片上有 **SKILL CARD**

点开 **作业反馈怎么写**：

- 「点赞 · 热度 0」→ 点赞 → 「已赞 · 热度 10」
- 围炉发：`我在作业评语里试过只标一个改点。` → 热度 **16**
- 关掉弹窗，榜上这张卡热度 16、位置上移

## 2. 推荐分

右侧「跨界漫游」点 **为什么推荐给我**。

应出现：`演示互补分 = 0.5×你能给她的需求 + 0.5×她能给你的需求 − 0.2×供给重叠。现在 60%（outbound 0.71 / inbound 0.50 / overlap 0.00）。不是概率。`

不应出现：「你关注研究方法……这是基于示例资料」。

## 3. 换卡

点 **系统韧性分析** → **申请交换**。

- **用我牌组里的哪张卡去换**：选 `论文创新判断 · 王展韬`
- 我是谁：`材料学博士生，在拆论文创新`
- 为什么：`系统怎么恢复，我想拿来看实验失败`
- 贡献说明：`我可以出一份实验失败记录当反例`

提交。左侧 **消息** → **模拟对方同意** → **加为同行**。

- 栖息地 → 我的牌组：`系统韧性分析` + 「换来的」
- 我的关系：林然，「交换后成为同行」

## 4. 伪 AIGC

左侧 **孵化室**。贴：

```
数据分析时经常对结论是否可靠产生分歧。首先整理原始记录。然后统一样本口径。接着比较不同方法。再检查异常案例。最后验证适用边界。
```

点 **收成一张草稿卡**。

商量三轮（不要换说法）：

1. `第三步太虚了` → 第 3 步变成「写出可检查的结果：比较不同方法」
2. `加一个反例：口径一周改三次就会假` → 局限追加该句
3. `改标题叫口径判断` → 标题「口径判断」，提示三轮到了

第四轮输入框和「商量」应禁用。

## 5. 共创

左侧 **共创实验室**（必须先做完第 3 步）。

标题应带「系统韧性分析」。三问依次答：

1. `我保验证边界，她保先失效的部件`
2. `我出一份实验失败记录当反例`
3. `贡献后开放`

点 **合成一个复合 Skill**。回 Skill Zoo 搜合成名。

期望卡名：**系统韧性分析 × 论文创新判断**  
（旧版会合成「林然的共创方法」，那是 `c.to` 用了作者名，已改代码。若仍看到旧名，删 `skill-zoo:v1` 后从第 3 步重走。）
