# Skill Zoo MVP — 2026-09-13

## 目标与闭环
让创作者把真实经验写成方法，发布后由同行使用、提交案例和改进建议，再发布新版本。3D 形象是方法的视觉标识。

## 验收标准
两账号验证：A 创建发布 → B 搜索收藏反馈/交换 → A 收通知接受 → 双方勾选任务 → A 更新版本。刷新与退出后仍能找回数据；B 无法修改 A 的 Skill、查询 A 的生成任务或操作别人的通知。未登录/跨站写请求拒绝。第三方超时不自动重试付费创建。

## 质量与来源可见化（当前开发切片）

### 用户问题
用户在尝试一个 Skill 前，需要知道它来自什么经验、经过了多少次验证、适合哪些场景，以及当前仍有哪些边界。作者也需要一个清晰入口，让读者从方法进入作者主页或交换经验。质量信息必须能追溯到可见数据，不能用没有依据的综合分数制造权威感。

### 用户故事
- 作为方法使用者，我可以在详情页看到作者经历来源、版本历史、案例和反馈数量，再决定是否尝试。
- 作为方法使用者，我可以看到适用边界和已知局限，并知道这些内容是否已经得到独立案例验证。
- 作为贡献者，我的案例或反馈会出现在贡献者列表中，并能触发作者通知。
- 作为读者，我可以从 Skill 详情页认识作者，并发送一张说明来意和贡献内容的交换卡。
- 作为评委，我可以沿着“经历 → 方法 → 案例/反馈 → 版本”链路核验产品承诺。

### 详情页必须展示
- **来源**：作者身份、方法由哪段真实经历提炼而来；若为规则提炼草稿，明确标注“规则提炼草稿，请作者核验”。
- **适用范围**：问题、输入、输出、步骤、真实案例、适用边界与已知局限。
- **验证证据**：当前版本号和发布时间、案例数量、反馈数量、贡献者名单；没有数据时显示“暂无”，不得填充虚构数字。
- **质量解释**：若展示评分或推荐，必须同时展示计算依据（例如案例、反馈、版本和贡献者计数）及更新时间；数据不足时显示“证据不足”，不输出确定性结论。
- **关系入口**：作者信息旁提供“认识作者/发送交换卡”操作，并说明交换卡需要填写的来意和可贡献内容。

### 验收标准
1. 作者发布一个 Skill 后，未登录访客可以打开公开详情，并看到来源、完整方法字段、适用边界、版本历史和当前案例/反馈计数。
2. 另一账号提交一条案例或反馈后，详情页显示该反馈和贡献者；作者收到一条可读通知。刷新页面后上述数据仍然存在。
3. 详情页的质量信息只引用服务端记录。没有案例、反馈或版本证据时，页面显示空状态或“证据不足”，不能出现固定演示数据。
   服务端详情响应中的 `quality` 至少包含 `score`、`label`、`confidence`、`feedbackCount`、`caseCount`、`helpfulCount`、`unfitCount`、`versionCount`、`contributorCount`、`source`、`sourceVerified` 和 `signals`；`score` 必须由这些可见信号确定性计算。
4. 详情页的“认识作者”入口可打开交换卡表单；提交后接收者在消息中心看到发送者、来意和愿意贡献的内容，并可接受或婉拒。
5. 非作者无法编辑、删除或查看作者私有草稿；反馈和贡献者数据不会泄露未公开 Skill 的内容。
6. 键盘可以完成详情页浏览、反馈提交和交换卡提交；加载失败时显示可重试的错误状态。

### 不在本切片范围内
本切片不引入黑盒 AI 评分、邮件验证、付费解锁或自动内容审核。规则提炼只生成可编辑草稿，作者仍需核验事实、适用边界和风险后才能发布。

## 上线边界
本地数据库不等于已部署云数据库。正式上线需真实 D1 绑定、HTTPS、Tripo 服务端密钥及允许生成的用户 ID。邮件验证、找回密码、OAuth、模型永久对象存储、自动内容审核和 LLM 执行引擎作为下一版，当前不假装这些能力已具备。当前 Skill 全部为公开方法或作者私有草稿，不实现付费/交换解锁策略。

## 下一阶段开发切片

1. **协作闭环可见化**：通知中心显示未读数、交换卡状态和任务截止时间，并可直接回到相关 Skill。
2. **质量与安全**：统一文本长度与频率限制，增加审核操作日志和隐藏内容提示。
3. **搜索与发现**：将当前字符串匹配升级为 SQLite FTS，并展示匹配字段与推荐原因。
4. **3D 资产可靠性**：将 Tripo 临时链接复制到对象存储，记录提示词和模型版本，重试前再次确认费用。
5. **可观测性**：记录 API 错误、任务耗时和反馈转化率，提供基础统计页面。

每个切片都必须满足：刷新后数据仍在、跨用户访问被拒绝、键盘可操作，并通过 `npm test`、`npm run typecheck` 和 `npm run build`。
