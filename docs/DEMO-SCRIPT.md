# 本地实测脚本（1→5 + 本轮四条）

http://localhost:3000/

旧数据干扰：F12 → Application → Local Storage → 删除 `skill-zoo:v2` → 刷新。
（`skill-zoo:v1` 是上一版命名 bug 的旧状态，页面会自己清掉。）

---

## 1. 商城

左侧 **Skill Zoo**。

应看到：

- 「50 个方法，13 位作者，正在让经验发芽」
- 排序 **热度榜**
- 热度条 NO.1：**热度 330 法律论文精读 陈沐**
- 卡片上有 **SKILL CARD**
- 作者名可以点（下划线点线）→ 见「6. 作者页」

点开 **作业反馈怎么写**：

- 「点赞 · 热度 0」→ 点赞 → 「已赞 · 热度 10」
- 围炉发：`我在作业评语里试过只标一个改点。` → 热度 **16**
- 关掉弹窗，榜上这张卡热度 16、位置上移

## 2. 推荐分

右侧「跨界漫游」点 **为什么推荐给我**。

应出现：`演示互补分 = 0.5×你能给她的需求 + 0.5×她能给你的需求 − 0.2×供给重叠。现在 60%（outbound 0.71 / inbound 0.50 / overlap 0.00）。不是概率。`

不应出现：「你关注研究方法……这是基于示例资料」。

## 3. 换卡

点 **系统韧性分析** → **申请交换**。

（这张是完全开放的，所以按钮里还有「收入我的沉淀」。脚本故意走交换，为了把「换卡 → 同行 → 共创」串起来。）

- **用我牌组里的哪张卡去换**：选 `论文创新判断 · 王展韬`
- 我是谁：`材料学博士生，在拆论文创新`
- 为什么：`系统怎么恢复，我想拿来看实验失败`
- 贡献说明：`我可以出一份实验失败记录当反例`

提交。左侧 **消息** → **模拟对方同意** → **加为同行**。

- 栖息地 → 我的牌组：`系统韧性分析` + 「换来的」
- 我的关系：林然，「交换后成为同行」

## 4. 伪 AIGC

左侧 **孵化室**。贴：

```
数据分析时经常对结论是否可靠产生分歧。首先整理原始记录。然后统一样本口径。接着比较不同方法。再检查异常案例。最后验证适用边界。
```

点 **收成一张草稿卡**。

商量三轮（不要换说法）：

1. `第三步太虚了` → 第 3 步变成「写出可检查的结果：比较不同方法」
2. `加一个反例：口径一周改三次就会假` → 局限追加该句
3. `改标题叫口径判断` → 标题「口径判断」，提示三轮到了

第四轮输入框和「商量」应禁用。

## 5. 共创

左侧 **共创实验室**（必须先做完第 3 步）。

- 标题：**系统韧性分析 × 论文创新判断**
- 两张卡的槽位：「系统韧性分析 · 来自 林然」「论文创新判断 · 我的牌组」
- 三问依次答：
  1. `我保验证边界，她保先失效的部件`
  2. `我出一份实验失败记录当反例`
  3. `贡献后开放`

点 **合成一个复合 Skill**。

- 任务进度：三问后 **5 / 6** → 合成后 **6 / 6**
- 族谱：两张亲本 → 新卡
- 回 Skill Zoo 搜 `×` → 命中 **系统韧性分析 × 论文创新判断**

（旧版会合成「林然的共创方法」，那是 `c.to` 用了作者名，已修。）

## 6. 三条门（本轮新增）

在 Skill Zoo 各点开一张，看按钮**不一样**：

| 卡 | 门 | 弹窗里的按钮 |
|---|---|---|
| 最少代码能跑（阿北） | 完全开放 | 申请交换 / **收入我的沉淀** |
| 公众号长文去杂质（纪衡） | 交换后开放 | 申请交换 |
| 法律论文精读（陈沐） | 贡献后开放 | **交一份反例换开放**（没有申请交换） |

走一遍贡献换开放：

1. 点 **法律论文精读** → **交一份反例换开放**
2. 贡献框里写：`我拿这套五问法审过一份保密协议。问到第三问时对方当场改了口径。`
3. 提交 → 提示「贡献已交给作者」→ 弹窗里按钮变成「已交贡献 · 等作者确认」
4. 左侧 **消息** → 「我交出去的贡献」→ **模拟作者通过**
5. 再点开 **法律论文精读** → 5 步工作流程可见，顶部写「贡献已通过 · 完整步骤已开放」
6. 热度仍是 **330**：贡献不算成交，不加 15

## 7. 入站信（本轮新增）

左侧 **消息**，第一栏「收到的交换申请」应有 **3 封待回**（纪衡 / 周遥 / 柯予，按货架现算）。

点第一封的 **同意交换**：

- 卡片变「已交换 · 已是同行」
- 栖息地牌组多了《公众号长文去杂质》，标「换来的」
- 我的关系出现纪衡
- 热度榜上该卡 +15
- 左侧「消息」角标从 3 减到 2

第二封点 **婉拒** → 变「已婉拒」，角标再减 1。

## 8. 刷新 / 后退 / 深链（本轮新增）

- 停在共创实验室按 **F5** → 还在共创实验室（地址栏 `?page=colab`）
- 点开一张卡再 F5 → 卡片仍开着（地址栏带 `&skill=<id>`）
- 消息 → 浏览器 **后退** → 回到上一屏，状态还在
- 直接把地址栏改成 `?page=colab&skill=3` 回车 → 落在共创实验室并开着系统韧性分析
- **合成一张新卡后必须刷新一次**：卡片和图标都该在、控制台无报错（`icon` 落盘的坑）

## 9. 手机宽

窗口拖到 400px：消息页三栏收成一栏，卡片按钮不溢出，没有横向滚动条。
