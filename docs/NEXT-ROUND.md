## 下一轮做什么（只前端，按路演收益排）

### A1. 钉死 3 分钟演示脚本（先写后改）

固定一条，所有改动对齐它，不要两条故事并行：

1. 商城热度榜，点开最热「法律论文精读」
2. 点赞 + 一条评论，热度条变动
3. 切「为你发现」，打开林然，点「为什么推荐给我」（必须看到供需分解）
4. 申请交换 → 消息里模拟对方同意 → 5 步解锁 → 我的沉淀出现
5. 加为同行 → 关系图谱出现这个人
6. （有余量）共创实验室用刚交换的两条合成一条，回到商城能搜到

把脚本写成 `docs/DEMO-SCRIPT.md`，队长路演按这个点。

### A2. 让模块二「看得见」（半天空）

PRD 公式已经在 `lib/bilateral-match.ts`。缺的是 UI。

- 「为什么推荐给我」展示：你的供给、对方需求、对方供给、你的需求、α/β/γ、三项点积、最终分
- 文案写「演示互补分，不是概率」
- 右侧栏只留一套分，删掉 `complementScore` 启发式或降为脚注
- 栖息地不再出现任何写死百分比

这是评委追问匹配时唯一能挡得住的一屏。

### A3. 让模块三在单机上闭环（一天）

不需要服务器。

- **交换后开放**：未成交只给问题 + 边界预告，成交后给 5 步（已有，UI 要更明显）
- **贡献后开放**：围炉提交「反例/交叉测试」≥ 8 字 → 消息里多一条「待作者审核」→ 按钮「模拟作者通过」→ 解锁；评论本身继续计热度，但不等于解锁
- **完全开放**：保持一键收入沉淀
- 消息页去掉三条写死人设，改成：我发出的卡 + 从目录抽 2–3 条入站申请（绑定真实 `skillId`）
- 共创实验室：有已成交交换才显示那两个人的 Skill 名；没有成交时空状态，不要裁判文书

族谱：合成时写入 `parentIds`，页面按这个渲染。不要再画静态箭头。

### A4. 作者页 + 热度跟人走（半天，商城像社交）

点头像/作者名 → 同一套 Dialog 或栖息地滤镜：此人所有 Skill、作者热度（名下 heat 之和）、能否交换。

热度榜旁边加「作者热度」不是必须；有作者页就够。50 条货没有作者主页，商城仍像货架不是社交。

### A5. 深链（半天）

`?page=zoo|habitat|incubator|colab|inbox|graph&skill=19`

刷新、后退、分享当前 Skill。DEMO-DELIVERY-PLAN 第 6 条，一直没做。路演切屏失误时能救场。

### A6. Demo 质感（穿插，不单独开一轮）

- 宽屏三列已有；窄屏确认 50 张卡不撑爆
- 刘看山 GIF 仍大，能压就压，压不了就默认「暂停动画」给路演电脑
- `garden.png` 零引用，确认后删（删文件需豪哥点头）
- 孵化室规则提炼留下，按钮文案改成「按 5 步规则提炼（不是模型）」——诚实比假 LLM 安全
