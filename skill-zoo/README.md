# Skill Zoo

让经验长成 Skill，让 Skill 连接到人。

当前版本是单浏览器卡片社交：50 张 Skill 卡、13 位作者。热度只排序、换不到货。换卡必须出自己牌组里的一张。开放分三条门：完全开放直接收入、交换后开放拿卡换、贡献后开放交一份反例等作者通过。孵化室是规则共拟（伪 AIGC，三轮），不是大模型。

## 本地运行

需要 Node.js 22.13.0 或更高版本及 npm。

```sh
cd skill-zoo
npm ci
npm run dev
```

打开终端输出的本地地址。

## 可复现检查

```sh
npm test
npm run typecheck
npm run build
```

`npm test` 使用 Node 内置测试运行器，不需要 API key。覆盖规则提炼、互补打分、热度公式、赞/评约束、交换解锁、贡献换开放、入站来信、深链路由、落盘字段与商城排序。

## 构建

```sh
npm run build
```

## 目录

- `app/`：页面、布局与响应式样式。
- `components/`、`hooks/`、`lib/`：复用组件和工具。
- `public/kanshan/`：刘看山动图及减少动态效果时使用的静态图片。
- `package-lock.json`：锁定项目依赖。
- `.openai/hosting.json`：现有 Sites 项目关联配置，不含访问凭证。部署到其他项目时需由维护者调整关联。

## 原型范围

使用 `data/skills.json` 与 `data/people.json` 的 Mock 社区。收藏、赞、评、交换、贡献、好友存在浏览器 `skill-zoo:v2`（`skill-zoo:v1` 会被自动清掉）。交换卡不会发给真人，消息页的来信按货架本地生成。规则提炼不是大模型。热度是演示加权。当前屏与打开的那张卡写在地址栏（`?page=…&skill=…`），刷新和后退都落在原处。

推荐和共创主持人内容仍为演示；成长评估会调用维护者配置的真实文本模型（`EVALUATION_*`，默认关闭），未配置时禁用，不生成假分数。

## Skill 成长评估

在孵化室填写方法说明和案例，点击「评估这个 Skill」，查看六维文档质量报告、原文依据与三条改进建议。完整配置、限制及验收方式见 [开发说明](docs/skill-evaluation.md)。

## 当前限制

- 没有认证、数据库或多用户同步。唯一的服务端接口是成长评估（`/api/skill-evaluations`），未配置模型时返回 503 并在页面上显示「尚未启用」。
- 对方同意交换是本机「模拟对方同意」。
- `npm run lint` 仍有基线错误，主要来自 shadcn UI 模板；类型检查、测试和生产构建应通过。
- `tsconfig.tsbuildinfo` 是本地缓存，不应提交。
