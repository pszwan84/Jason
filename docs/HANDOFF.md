## 给下一个 agent 的六句话

1. 活代码只有 `skill-zoo/app/page.tsx` → `lib/*` + `data/*.json`。不要复活 `components/zoo/`。
2. **没有货币。** 热度只排序。社交原子是 **卡**：用自己牌组里的一张去换别人的一张。
3. **三种门，三条不同的路**：完全开放 = 一键收入；交换后开放 = 换卡；贡献后开放 = 交一份反例/交叉测试，**作者通过才开放**（不是换卡）。
4. **没有真 AI。** 孵化室 / 共创主持人是规则引擎，同一句话永远改同一处。路演就这么讲。
5. **`icon` 永远不要落盘。** localStorage 键是 `skill-zoo:v2`（v1 自动清）。见下方「icon 崩溃」。
6. **URL 是导航的第二真相**：`?page=zoo|habitat|incubator|colab|inbox|graph`，开卡再加 `&skill=<id>`。刷新、后退、分享都落在原处。
7. **8090 不要动**（被「支线」占着）。详见 `docs/HANDOFF-DEPLOY.md`。未授权不许部署、不许改 `.env`、不许删文件。

### icon 崩溃（本轮实测撞出来的）

`icon` 是 React 组件。上一轮注释写「stringify 会丢弃它」——**只对函数组件成立**。lucide 的图标是 `forwardRef` 对象，过一遍 JSON 会变成 `{}`，读回来当组件渲染就抛 `Element type is invalid: … got: object`。

触发条件很普通：**发布或合成过一张本地卡 → 刷新**。上一轮 URL 永远回首页，刷新少有人做；本轮加了深链，刷新变成常规动作，就撞上了。

修法两条，缺一不可：

1. `SKILL_FIELDS` 白名单里**删掉 `icon`**，落盘不带组件；
2. 读回时用 `isIconType()` 把关（函数或带 `$$typeof` 的对象才算图标），`{}` 一律拒绝，按 `category` 回填。

复测：合成一张卡 → 刷新 → 卡片仍在、图标仍在（回填成该馆的图标）、控制台 0 报错。

## 下一轮方案（只打磨实测露出来的洞）

按评委追问顺序，不要开新页、不要上货币、不要接真模型。

### P1 — 现在仍然假 / 说不圆的地方

1. **完全开放的卡仍然给「申请交换」。** 语义上它不用换。之所以留着：脚本第 3 步就是靠它演示「换卡 → 同行 → 共创」整条链，而系统韧性分析恰好是完全开放。要么把脚本换成一张交换后开放的卡（如纪衡《公众号长文去杂质》），要么接受这个不一致——**别偷偷改，先定脚本再改代码**。
2. **消息页没有共创邀请。** 只有交换申请和我的贡献。队长若要「热闹」，从目录再抽一条共创邀请，但接受后必须能进共创（现在没成交卡进不去，容易死路）。
3. **共创任务清单 6 项有 2 项预勾。** 这是故意留的：三问后正好 5/6，合成后 6/6（本轮补的）。若把预勾去掉，三问后只有 3/6，看着像没干完。
4. **只有 `page` / `skill` 进 URL。** 搜索词、排序、分类、作者页刷新后会丢。评委不会追问，别为这个拆 `page.tsx`。
5. **关系图谱只有「你 + 同行」。** 节点点了开对方的卡，但没有关系强度、没有时间线（侧栏「你和林然」是写死的 3/18）。要动先问队长。

### P2 — 别做

- 积分 / 代币 / 热度换次数
- 真 LLM、真流式
- REST API、账号、8090 部署
- 再扩货架（50 够）
- 拆 `page.tsx`、改视觉体系

模块一（知乎链接 + LLM）若队长强要：继续用 `distill.ts` 吃**粘贴正文**，标题就写规则提炼。现场不要调模型。
