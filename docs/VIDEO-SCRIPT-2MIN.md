# 2 分钟演示视频 · 口播稿

> 用在 `integration/full-demo-20260915`（全量分支）上录。同一条稿在 `feat/studio-mvp-20260914` 也能走。
> 全部动作都是真的，全部数字都能在屏幕上指出来。**不许讲「已上线 / 有真实用户 / 已接大模型」。**
> 总时长 2:00，口播合计约 440 字（中文演示语速约 220 字/分钟）。

---

## 录前 60 秒准备

1. 打开 http://localhost:3000/ ，F12 → Application → Local Storage → **删 `skill-zoo:v2`** → 刷新（干净状态：无旧合成卡、无旧好友）。
2. 右上角点 **暂停动画**（刘看山不动，录屏不抖）。
3. 浏览器窗口 1440×900 或以上，缩放 100%，**关掉其他标签页和通知**。
4. 先手动做完 `docs/DEMO-SCRIPT.md` 的第 3 步（换卡 → 消息 → 模拟对方同意 → 加为同行），**不要录进去**。这是为了 1:20 的共创屏有已成交的卡。
5. 把下面三句共创答案先粘在记事本里，录的时候直接粘贴，省 10 秒：
   - `我保验证边界，她保先失效的部件`
   - `我出一份实验失败记录当反例`
   - `贡献后开放`
6. 试录 10 秒，确认录屏不卡、鼠标移动看得见（鼠标别甩太快）。

## 0:00 – 0:12 〈开场〉

**口播**（45 字）：
> AI 时代每个人都在攒方法，但方法通常只留在一份 SKILL 文档里——你不知道它从哪来，也没法验证。我们做了 Skill Zoo：让经验长成一张卡，让卡连到人。

**画面**：商城首页定住不动，热度榜前五张卡可见（NO.1 法律论文精读 陈沐 · 热度 330）。

---

## 0:12 – 0:27 〈商城不是货架〉

**口播**（55 字）：
> 五十张方法卡，十三位作者。热度只买曝光——十个赞加六条评，加一次成交，公式就写在榜下面，换不到货。点作者的名字，能看到他全部的方法和作者热度。

**画面**：
1. 鼠标扫过货架，停在 **NO.1 法律论文精读**。
2. 点卡片上的作者名 **陈沐** → 弹出「陈沐 的卡」：3 张卡 / 作者热度 / 2 张可换 / 1 张要贡献。
3. 关掉弹窗。

**提示**：作者热度 = 名下每张卡热度之和，这张弹窗上自己写着，评委问就指。

---

## 0:27 – 0:55 〈三种门 + 推荐分〉

**口播**（100 字）：
> 每张卡有三种门。完全开放，一键收入。交换后开放，拿你牌组里的一张来换。贡献后开放，换不了——你得交一个可验证的反例，作者通过才开门。
> 推荐也不是玄学：0.5 乘你能给对方的，加 0.5 乘对方能给你的，减 0.2 供给重叠。这是互补分，不是概率。

**画面**（三个弹窗各停 3 秒，让眼睛跟上）：
1. **最少代码能跑**（阿北）：按钮是「申请交换 / 收入我的沉淀」——完全开放。
2. **公众号长文去杂质**（纪衡）：只有「申请交换」——交换后开放。
3. **法律论文精读**（陈沐）：只有「**交一份反例换开放**」，没有申请交换——贡献后开放。
4. 右侧「跨界漫游」→ 点 **为什么推荐给我** → 出现公式拆解，鼠标划到 `0.5×… + 0.5×… − 0.2×…` 与 `60%` 上。

**提示**：这一步是 2 分钟里信息量最大的，动作要干净：点开 → 停 → 关，不要来回找。

## 0:55 – 1:20 〈换卡换出一个同行〉

**口播**（90 字）：
> 用我的《论文创新判断》去换林然的《系统韧性分析》。申请发出去，出现在消息里。这里还有三封别人发来的交换申请——它们不是写死的，是按货架现算的。同意，对方的卡进我的牌组，我们成为同行，他的热度也涨一次成交。

**画面**：
1. 点开 **系统韧性分析** → **申请交换** → 表单（下拉里能看到「论文创新判断 · 王展韬」）→ 提交（表单可以提前填好，现场只按提交）。
2. 左侧 **消息** → 上面是「收到的交换申请 3 封待回」→ 点第一封的 **同意交换** → 卡片变「已交换 · 已是同行」。
3. 切 **我的栖息地** → 我的牌组出现《公众号长文去杂质》标「换来的」。
4. 切 **我的关系** → 图谱上多一个同行。

**提示**：1:00 之后动作变快，如果时间超了，**先砍这一步的第 3 小步**（栖息地牌组），关系图谱保留——「交换长出关系」是这一段的结论。

## 1:20 – 1:42 〈规则共拟 + 共创〉

**口播**（80 字）：
> 一段经历，先收成一张五步草稿。跟刘看山商量三轮——「第三步太虚了」，它把第三步改成能检查的动作。这不是大模型，是规则共拟，同一句永远改同一处，所以敢现场敲。两张卡再到共创实验室对齐三问，合成一条谁都没有的新方法。

**画面**：
1. 左侧 **孵化室** → 粘贴经历（提前准备好，直接粘贴）→ **收成一张草稿卡** → 出现刘看山气泡和 5 步。
2. 输入框打 `第三步太虚了` → **商量** → 第 3 步当场变成「写出可检查的结果：比较不同方法」。
3. 左侧 **共创实验室** → 标题已是「系统韧性分析 × 论文创新判断」→ 三句答案粘贴 + **回答并继续** ×3 → **合成一个复合 Skill** → 任务进度 6/6。

**提示**：孵化室下方还有一块「成长评估（另一条线）」，**不要点、不要露**——没配模型时它是禁用状态，出现在视频里只会让人问「这是不是坏的」。

## 1:42 – 2:00 〈收尾〉

**口播**（70 字）：
> 合成的新卡回商城里能搜到，亲本写在族谱上。刷新、后退都不丢屏，状态就在地址栏里，可以直接分享。Skill Zoo 不想做知识库，我们想让它做到：让方法被看见，让认真做事的人被认识。

**画面**：
1. 左侧 **Skill Zoo** → 搜索框输入 `×` → 命中「系统韧性分析 × 论文创新判断」。
2. 按 **F5** → 页面回来还在同一屏（这一下要让人看见地址栏里的 `?page=…`）。
3. 定格在合成卡上收尾。

## 必须说出口的三句诚实话（散在上面各段里，别省）

- 「示例社区，交换不会发给真人。」
- 「热度是演示热度，只影响排序，换不到货。」
- 「刘看山是规则共拟，不是大模型。」

## 不能说的话

- 不要说「已经上线 / 已经有真实用户」。
- 不要说「我们接了大模型做评估」（评估那条线没配模型，别碰）。
- 不要说「热度高就能换到更多货」——热度只买曝光。

## 点错了的三句救场

1. 弹窗开错：`这里我先看另一张卡` → 关掉，重开（不要解释为什么点错）。
2. 消息页状态不对：`这个示例社区的状态存在浏览器里` → 顺手刷新一下，接「刷新也不丢屏」。
3. 共创合成按钮点了没反应（三问没答完）：`主持人三问得答完才让合成，这是故意的` → 补答第三问。

## 时长兜底

- 超时：先砍「0:12–0:27」的作者页（3 秒），再砍「0:55–1:20」的第 3 小步。
- 还有余量（1:50 就讲完了）：在收尾前加 5 秒，对着热度榜说一遍公式 `10×赞 + 6×评 + 15×成交`。
