## 下一轮做什么（只前端，按路演收益排）

### A1. 钉死 3 分钟演示脚本（先写后改）— ✅ 已落地，见 `docs/DEMO-SCRIPT.md`

固定一条，所有改动对齐它，不要两条故事并行：

1. 商城热度榜，点开最热「法律论文精读」
2. 点赞 + 一条评论，热度条变动
3. 切「为你发现」，打开林然，点「为什么推荐给我」（必须看到供需分解）
4. 申请交换 → 消息里模拟对方同意 → 5 步解锁 → 我的沉淀出现
5. 加为同行 → 关系图谱出现这个人
6. （有余量）共创实验室用刚交换的两条合成一条，回到商城能搜到

把脚本写成 `docs/DEMO-SCRIPT.md`，队长路演按这个点。

### A2. 让模块二「看得见」（半天空）— ✅ 上一轮已落地

PRD 公式已经在 `lib/bilateral-match.ts`。缺的是 UI。

- 「为什么推荐给我」展示：三项点积、α/β/γ、最终分，文案写「演示互补分，不是概率」（已做）
- 侧栏还留着一行 `complementScore` 启发式当脚注（`lib/match.ts`）。要清就一并清掉，属可选。

### A3. 让模块三在单机上闭环（一天）— ✅ 已落地

不需要服务器。

- **交换后开放**：未成交只给问题 + 边界预告，成交后给 5 步（已有，UI 要更明显）
- **贡献后开放**：交「反例/交叉测试」≥ 8 字 → 消息里多一条「待作者确认」→ 按钮「模拟作者通过」→ 解锁；评论本身继续计热度，但不等于解锁 —— 注意：最终不是走围炉评论，而是详情弹窗里的独立按钮 + 独立弹窗，评论仍然只加热度
- **完全开放**：保持一键收入沉淀
- 消息页去掉写死人设，改成：我发出的卡 + 从目录算出的 3 条入站申请（绑定真实 `skillId`，见 `lib/inbox.ts`）
- 共创实验室：有已成交交换才显示那两张 Skill 名；没有成交时空状态，不出现裁判文书
- 族谱：合成时写入 `parentIds`（= 对方卡 id + 我的卡的 id），页面按这个渲染

### A4. 作者页 + 热度跟人走（半天，商城像社交）— ✅ 已落地

点卡片作者名 / 详情页「他的其他卡」 → 作者页弹窗：此人所有 Skill、作者热度（名下 heat 之和）、可换与要贡献的张数、加为同行。
